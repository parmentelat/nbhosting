### the move

* we move *old students* to /nbhosting/archived-students
* based on whether they have accessed any of their files since september 2022
* as of jan 2024, we take 500 days as a cutoff, which is about 1.5 years
* using `find -type f -atime -500` we detect the files that have been accessed within the last 500 days
* we keep only the folder names, and we sort them
* which gives us a list of students to preserve here

### sizes

* with N=500 (-> 2022-08-28), we keep 16.143 students

* with N=300 (-> 2023-03-16), we keep  9.894 students

### the script

```bash

function show-cutoff() {
    local cutoff="$1"; shift
    python << EOF
import datetime
N=$cutoff
now = datetime.datetime.now()
before = now - datetime.timedelta(days=N)
print(f"{N} days before was {before:%Y-%m-%d}")
EOF
}

function find-recent-folders() {
    local cutoff="$1"; shift
    local output=/tmp/recent-students-$cutoff
    find . -type f -atime -$cutoff -printf '%P\n' | cut -d/ -f1 | sort -u > $output
    echo "found $(wc -l < $output) students"
    echo "saved in $output"
}

N=730
show-cutoff $N
find-recent-folders $N

mkdir -p /nbhosting/archived-students

for d in *; do
    if grep -q -E "^$d$" /tmp/recent-students-$N; then
        echo "keeping $d"
    else
        echo "moving $d"
        mv $d /nbhosting/archived-students
    fi
done
```
